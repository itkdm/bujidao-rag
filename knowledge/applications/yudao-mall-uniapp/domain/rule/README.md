# yudao-mall-uniapp 规则知识索引

`domain/rule/` 用于沉淀学生身份、展示、下单限制、校园场景等规则。

## 当前状态

当前暂无正式 rule 知识。学生端规则需等待夸友小程序业务改造明确后再沉淀。

## 使用规则

1. 未经确认的学生身份、下单、展示或校园场景规则不得写入正式 rule。
2. 需要了解产品规则时，优先读取 `docs/01-product/`。
3. 需要新增规则知识时，使用 `knowledge/template/rule-template.md`。
