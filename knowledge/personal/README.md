# personal/

## 目录定位

`personal/` 用于存放个人经验、踩坑记录、临时理解和碎片素材。这里的内容是入库前的原始素材，不等同于正式知识。

## 应包含的内容

- 个人研发经验、踩坑记录与临时理解。
- 尚未结构化、需要沉淀的原始经验素材与碎片笔记。

## 不应包含的内容

- 已经整理确认、可作为团队结论的知识：应先进入 `candidate/`，再进入 `main/` 或 `applications/`。
- 跨应用统一、需要全员遵守的正式规则：不放入本目录。

## 维护规则

- 个人笔记可以作为知识入库素材，但不能直接代表项目正式结论。
- 多次验证或需要复用的内容，先整理到 `candidate/`。
- 经确认后，再进入 `main/` 或 `applications/`。
