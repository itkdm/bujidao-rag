# 个人笔记索引

`personal/` 用于存放布吉岛的个人经验、踩坑记录、临时理解和碎片素材。这里的内容不等同于正式知识。

## 当前状态

## 使用规则

1. 个人笔记可以作为知识入库素材，但不能直接代表项目正式结论。
2. 多次验证或需要复用的内容，先整理到 `candidate/`。
3. 经确认后，再进入 `main/` 或 `applications/`。
