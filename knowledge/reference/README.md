## 使用规则

1. AI 不应把本目录内容直接当成目标项目已经确认的功能、规则或技术结论。
2. 需要核对上游能力、官方约定或证据来源时，才读取本目录。
3. 从参考资料提炼出的稳定知识，应写入 `candidate/` 或对应正式知识文件，并保留证据路径。
4. 不再参与当前证据检索但仍需追溯的资料，连同来源说明和本地资源移动到 `archive/reference/`，并更新引用。

## 原始资料来源头

`ruoyi-vue-pro官方文档/` 是抓取后原样保存的上游资料。文件开头的 `title`、`source_url`、`official_path`、`crawled_at` 只用于来源追溯，不属于团队知识字段，也不要求人工维护。

原始导入资料根目录使用普通文件 `.raw-reference` 显式标记。标记必须位于 `reference/` 的某个资料子目录，不能直接放在 `reference/` 根部，也不能使用符号链接。校验器只豁免标记目录及其后代；标记随整份资料移动到 `archive/reference/` 后，来源头和本地资源仍会被正确识别。目录名称不参与判断，其他参考资料不会自动获得豁免。

原始导入快照可能保留上游站点的绝对链接、抓取时断链或特殊资源映射，因此通用 Markdown 链接校验不会进入标记目录内部。受管理知识指向这份资料的链接仍会校验；原始快照自身的资源完整性应由抓取清单或对应导入工具验证。
