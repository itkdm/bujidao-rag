友情提示：

百度千帆 API 提供了 V2 版本，项目当前通过 OpenAI 兼容协议接入文本对话；图片、向量能力暂未接入。

项目基于 Spring AI + 自己实现的 `models/yiyan`，实现 [文心一言](https://yiyan.baidu.com/) 的接入，底层复用兼容 OpenAI 协议的客户端：

| 功能 | 模型 | Spring AI 客户端 |
| --- | --- | --- |
| AI 对话 | ERNIE 5.1、ERNIE 5.0、ERNIE X1.1 等 | YiYanChatModel |
| AI 绘画 | 暂未接入 | 暂未接入 |

## 1. 申请密钥

由于文心一言是非开源的模型，所以无法私有化部署，需要去官网申请 API Key，然后通过项目自定义的 YiYanChatModel 接入。

### 1.1 申请百度云密钥

① 在 [百度智能云](https://cloud.baidu.com/) 上，注册一个账号。

② 在百度智能云的 [API Key 管理](https://console.bce.baidu.com/iam/#/iam/apikey/list) 页面，直接创建 API Key。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”（例如 `bce-v3/ALTAK-xxx/xxx`），不需要填写“自定义 API URL”（默认使用千帆 V2 地址）。

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E6%96%87%E5%BF%83%E4%B8%80%E8%A8%80-%E5%AE%98%E6%96%B9.png)

友情提示：

千帆 V2 使用 IAM Bearer Token 鉴权，只需要 API Key，不需要 Secret Key，也不需要创建应用。

## 2. 模型配置

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| ernie-5.1 | 65536 |
| ernie-5.0 | 65536 |
| ernie-x1.1 | 65536 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 YiYanChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.yiyan` 配置项，替换成你的！

```
yudao:
  ai:
    yiyan: # 文心一言
      enable: true
      api-key: ${YIYAN_API_KEY}
      model: ernie-5.1
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，YiYanChatModelTests 里有对应的测试用例，可以参考。
