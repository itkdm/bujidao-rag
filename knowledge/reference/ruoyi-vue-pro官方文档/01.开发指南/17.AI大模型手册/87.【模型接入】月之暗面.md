项目基于 Spring AI + 自己实现的 `models/moonshot`，实现 [Moonshot](https://www.moonshot.cn/) 的接入，底层复用兼容 OpenAI 协议的客户端：

| 功能 | 模型 | Spring AI 客户端 |
| --- | --- | --- |
| AI 对话 | kimi-k2.7-code、kimi-k2.6 等 | MoonshotChatModel |
| AI 绘画 | 不支持 | 暂未接入 |

## 1. 申请密钥

Moonshot 有开源模型，可以私有化部署。

不过官方 API 服务使用也比较方便，可以去官网申请 API Key，然后通过项目接入。

### 1.1 方式一：申请 Moonshot 密钥

① 在 [Moonshot](https://www.moonshot.cn/) 上，注册一个账号。

② 在 [Moonshot 开放平台 -> API Key 管理](https://platform.moonshot.cn/console/api-keys) 上，创建一个 API Key 密钥。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/Moonshot-%E5%AE%98%E6%96%B9.png)

## 2. 模型配置

友情提示：

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型，并选择前面配置的 Moonshot API 密钥。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| kimi-k2.7-code | 16384 |
| kimi-k2.6 | 262144 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 MoonshotChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.moonshot` 配置项，替换成你的！

```
yudao:
  ai:
    moonshot: # 月之暗面（KIMI）
      enable: true
      api-key: ${MOONSHOT_API_KEY}
      model: kimi-k2.6
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，MoonshotChatModelTests 里有对应的测试用例，可以参考。
