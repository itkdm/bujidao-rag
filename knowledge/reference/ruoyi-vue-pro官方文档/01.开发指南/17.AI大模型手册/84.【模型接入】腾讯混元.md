## 1. 申请密钥

由于腾讯混元是非开源的模型，所以无法私有化部署，需要去官网申请 API Key，然后通过 Spring AI 提供的客户端接入。

### 1.1 申请腾讯密钥

① 在 [腾讯云](https://curl.qcloud.com/cxA9d2Ik) 上，注册一个账号。

② 在 [TokenHub 控制台](https://console.cloud.tencent.com/tokenhub) 上开通混元模型，并在 [API Key 管理](https://console.cloud.tencent.com/tokenhub/apikey) 创建一个 API Key 密钥。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（项目默认使用 TokenHub 地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E8%85%BE%E8%AE%AF%E6%B7%B7%E5%85%83-%E5%AE%98%E6%96%B9.png)

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 HunYuanChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.hunyuan` 配置项，替换成你的！

```
yudao:
  ai:
    hunyuan: # 腾讯混元
      enable: true
      api-key: ${HUNYUAN_API_KEY}
      model: hy3-preview
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，HunYuanChatModelTests 里有对应的测试用例，可以参考。
