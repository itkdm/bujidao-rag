项目基于 Spring AI 提供的 [spring-ai-deepseek](https://github.com/spring-projects/spring-ai/tree/main/models/spring-ai-deepseek)，实现 DeepSeek 的接入：

| 功能 | 模型 | Spring AI 客户端 |

| AI 绘画 | Janus-Pro | 暂不支持 |

## 1. 申请密钥

DeepSeek 目前有 3 种方式，可以进行使用：

① 方式一：官方 API：DeepSeek 提供官方 API 服务，并且价格非常便宜，一般建议直接采用这种方式使用。

② 方式二：私有化部署：[DeepSeek](https://github.com/deepseek-ai) 有开源模型，所以可以本地私有化部署使用。

③ 方式三：云厂商部署：类似阿里云、字节、腾讯等厂商，私有化部署了 DeepSeek，然后提供 API 服务。

### 1.1 方式一：官方 API 申请

① 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 上，注册一个账号。目前，默认注册就送 500w tokens，还是蛮爽的。

② 在 [API keys](https://platform.deepseek.com/api_keys) 菜单，创建一个 API key 即可。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/DeepSeek-%E5%AE%98%E6%96%B9.png)

### 1.2 方式二：私有化部署

友情提示：

由于 DeepSeek V4 模型尺寸比较大，Ollama 暂未提供本地部署的官方方案。当然，感兴趣也可以试试社区模型 [deepseek-v4-flash](https://ollama.com/munoz_danilo/deepseek-v4-flash)。

所以下面仍然使用 `deepseek-r1` 作为本地私有化部署示例。

① 访问 [https://ollama.ai/download](https://ollama.ai/download)，下载对应系统 Ollama 客户端，然后安装。

② 安装完成后，在命令中执行 `ollama run deepseek-r1` 命令，一键部署 [deepseek-r1 开源模型](https://ollama.com/library/deepseek-r1)，默认跑的是 `deepseek-r1:7b` 模型。

---

部署完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。需要填写“密钥” + “自定义 API URL”（因为让 Spring AI 使用该地址）。如下图所示：

![私有的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/Ollama-%E5%AF%86%E9%92%A5.png)

如果想部署 deepseek 的其它模型，可以搜索 [deepseek](https://ollama.com/search?q=deepseek) 文档，执行不同的 `ollama run` 命令即可。

注意：使用该方式时，后续配置模型名时，需要使用 `deepseek-r1` 而不是 `deepseek-reasoner`！！！例如说：

![私有的聊天模型](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E9%80%9A%E4%B9%89%E5%8D%83%E9%97%AE-%E8%81%8A%E5%A4%A9%E6%A8%A1%E5%9E%8B-%E7%A7%81%E6%9C%89.png)

## 2. 模型配置

友情提示：

目前 `ai_model` 表中，已经预置了一些模型，可以直接使用！！！

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型。

模型有：`deepseek-v4-flash`、`deepseek-v4-pro`，可通过 [《DeepSeek API 文档》](https://api-docs.deepseek.com/zh-cn/) 查看。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| deepseek-v4-flash | 65536 |
| deepseek-v4-pro | 384000 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 DeepSeekChatModel 等对象，需要把 `application.yaml` 配置文件里的 `spring.ai.deepseek` 配置项，替换成你的！

```
spring:
  ai:
    deepseek: # DeepSeek
      api-key: ${DEEPSEEK_API_KEY}
      chat:
        options:
          model: deepseek-v4-flash
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，DeepSeekChatModelTests 里有对应的测试用例，可以参考。

## 4. 云厂商部署

除了 DeepSeek 官方 API，也可以通过云厂商部署的 DeepSeek 模型接入。不同厂商的 API URL、模型标识、thinking 返回格式可能不同，建议优先按厂商文档填写“自定义 API URL”和模型标识。

### 4.1 阿里云 API

① 参考 [《【模型接入】通义千问》](https://doc.iocoder.cn/ai/tongyi) 文档，申请阿里云密钥，并配置 API 密钥。

② 配置聊天模型时，字段可以按下面填写：

- 所属平台：`TongYi`
- 模型标识：`deepseek-v4-pro` 或 `deepseek-v4-flash`
- API 密钥：选择前面配置的阿里云密钥

具体模型可见阿里云百炼的 [deepseek-v4-pro](https://bailian.console.aliyun.com/cn-beijing#/model-market/detail/deepseek-v4-pro) 和 [deepseek-v4-flash](https://bailian.console.aliyun.com/cn-beijing#/model-market/detail/deepseek-v4-flash)。

### 4.2 腾讯云 API

① 如果使用腾讯云 TokenHub，可以参考 [《【模型接入】腾讯混元》](https://doc.iocoder.cn/ai/hunyuan) 文档，申请腾讯 API Key，并配置 API 密钥。

② 配置聊天模型时，字段可以按下面填写：

- 所属平台：`HunYuan`
- 模型标识：`deepseek-v4-flash` 或 `deepseek-v4-pro`
- API 密钥：选择前面配置的腾讯混元密钥

具体模型可见腾讯云 TokenHub 的 [deepseek-v4-flash](https://console.cloud.tencent.com/tokenhub/models/detail?modelId=deepseek-v4-flash&regionId=1&from=all) 和 [deepseek-v4-pro](https://console.cloud.tencent.com/tokenhub/models/detail?modelId=deepseek-v4-pro&regionId=1&from=all)。

### 4.3 字节火山云 API

① 参考 [《【模型接入】字节豆包》](https://doc.iocoder.cn/ai/doubao) 文档，申请字节密钥，并配置 API 密钥。

② 配置聊天模型时，字段可以按下面填写：

- 所属平台：`DouBao`
- 模型标识：`deepseek-v4-pro-260425` 或 `deepseek-v4-flash-260425`
- API 密钥：选择前面配置的字节豆包密钥

具体模型可见火山方舟的 [deepseek-v4-pro](https://console.volcengine.com/ark/region:ark+cn-beijing/model/detail?Id=deepseek-v4-pro) 和 [deepseek-v4-flash](https://console.volcengine.com/ark/region:ark+cn-beijing/model/detail?Id=deepseek-v4-flash)。

### 4.4 百度 API

① 参考 [《【模型接入】文心一言》](https://doc.iocoder.cn/ai/yiyan) 文档，申请百度千帆密钥，并配置 API 密钥。

② 配置聊天模型时，字段可以按下面填写：

- 所属平台：`YiYan`
- 模型标识：`deepseek-v4-pro` 或 `deepseek-v4-flash`
- API 密钥：选择前面配置的百度千帆密钥

具体模型可见百度千帆的 [DeepSeek-V4-Pro](https://console.bce.baidu.com/qianfan/modelcenter/model/buildIn/detail/am-ef6aeca66ed0?tab=version#DeepSeek-V4-Pro) 和 [DeepSeek-V4-Flash](https://console.bce.baidu.com/qianfan/modelcenter/model/buildIn/detail/am-c22b1beec35b)。

### 4.5 硅基流动 API

① 参考 [《【模型接入】硅基流动》](https://doc.iocoder.cn/ai/siliconflow) 文档，申请硅基密钥，并配置 API 密钥。

② 配置聊天模型时，字段可以按下面填写：

- 所属平台：`SiliconFlow`
- 模型标识：`deepseek-ai/DeepSeek-V4-Pro` 或 `deepseek-ai/DeepSeek-V4-Flash`
- API 密钥：选择前面配置的硅基流动密钥

具体模型可见硅基流动的 [DeepSeek-V4-Pro](https://cloud.siliconflow.cn/me/models?target=deepseek-ai/DeepSeek-V4-Pro) 和 [DeepSeek-V4-Flash](https://cloud.siliconflow.cn/models?target=deepseek-ai/DeepSeek-V4-Flash)。
