| 功能 | 模型 | Spring AI 客户端 |
| --- | --- | --- |

| AI 绘画 | 暂未接入 | 暂未接入 |

## 1. 申请密钥

由于字节豆包是非开源的模型，所以无法私有化部署，需要去官网申请 API Key，然后通过项目自定义的 DouBaoChatModel 接入。

### 1.1 申请字节密钥

① 在 [火山引擎](https://www.volcengine.com/experience/ark?utm_term=202502dsinvite&ac=DSASUQY5&rc=BQ4TPVC1) 上，注册一个账号。

② 在 [系统设置 -> API Key 管理](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey?apikey=%7B%7D) 上，创建一个 API Key 密钥。

![创建密钥](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/DouBao-%E5%88%9B%E5%BB%BA%E5%AF%86%E9%92%A5.png)

③ 在 [智能广场 -> 模型广场](https://console.volcengine.com/ark/region:ark+cn-beijing/model?vendor=Bytedance&view=LIST_VIEW) 上，开通 “Doubao-Seed-2.1-pro” 或 “Doubao-Seed-2.1-turbo” 模型。

![申请模型](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/DouBao-%E7%94%B3%E8%AF%B7%E6%A8%A1%E5%9E%8B.png)

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E5%AD%97%E8%8A%82%E8%B1%86%E5%8C%85-%E5%AE%98%E6%96%B9.png)

## 2. 模型配置

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| doubao-seed-2-1-pro-260628 | 262144 |
| doubao-seed-2-1-turbo-260628 | 262144 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 DouBaoChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.doubao` 配置项，替换成你的！

```
yudao:
  ai:
    doubao: # 字节豆包
      enable: true
      api-key: ${DOUBAO_API_KEY}
      model: doubao-seed-2-1-turbo-260628
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，DouBaoChatModelTests 里有对应的测试用例，可以参考。
