项目基于 Spring AI + 自己实现的 `models/baichuan`，实现 [百川智能](https://www.baichuan-ai.com/) 的接入，底层复用兼容 OpenAI 协议的客户端：

| 功能 | 模型 | Spring AI 客户端 |
| --- | --- | --- |
| AI 对话 | Baichuan-M3-Plus、Baichuan-M3、Baichuan4-Turbo 等 | BaiChuanChatModel |
| AI 绘画 | 暂未接入 | 暂未接入 |
| AI 向量 | Baichuan-Text-Embedding | 暂未接入 |

## 1. 申请密钥

百川智能历史上有[开源版本](https://github.com/baichuan-inc)，可以按需私有化部署。

当然，我们也可以直接使用官方的 API 服务，使用也比较方便。

下面，我们来看看这两种方式怎么申请（部署）？

### 1.1 方式一：官方 API 申请

① 在 [开放平台](https://platform.baichuan-ai.com/homePage) 上，注册一个账号。目前，默认注册就送 500w tokens，还是蛮爽的。

② 在 [API Key 管理](https://platform.baichuan-ai.com/console/apikey) 菜单，创建一个 API key 即可。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E7%99%BE%E5%B7%9D%E6%99%BA%E8%83%BD-%E5%AE%98%E6%96%B9.png)

### 1.2 方式二：私有化部署

参考 [https://github.com/baichuan-inc](https://github.com/baichuan-inc) 进行部署。

当然，貌似也能用 Ollama 部署，但是我没试，可见 [https://ollama.com/search?q=baichuan](https://ollama.com/search?q=baichuan) 。

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| Baichuan-M3-Plus | 8192 |
| Baichuan-M3 | 8192 |

具体模型列表和价格，可以查看 [百川智能价格说明](https://platform.baichuan-ai.com/prices)。

### 2.2 AI 绘图

百川暂时不支持绘图模型！！！

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 BaiChuanChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.baichuan` 配置项，替换成你的！

```
yudao:
  ai:
    baichuan: # 百川智能
      enable: true
      api-key: ${BAICHUAN_API_KEY}
      model: Baichuan-M3
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，BaiChuanChatModelTests 里有对应的测试用例，可以参考。
