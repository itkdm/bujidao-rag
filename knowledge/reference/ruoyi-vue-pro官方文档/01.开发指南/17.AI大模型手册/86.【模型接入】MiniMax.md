## 1. 申请密钥

MiniMax 有开源版本，可以私有化部署。

当然，我们也可以直接使用官方的 API 服务，提供了一定的免费额度，使用也比较方便

下面，我们来看看这两种方式怎么申请（部署）？

### 1.1 方式一：申请 MiniMax 密钥

① 在 [MiniMax](https://www.minimaxi.com/) 上，注册一个账号。

② 在 [MiniMax 开放平台 -> 账户管理 -> 接口密钥](https://platform.minimaxi.com/user-center/basic-information/interface-key) 上，创建一个 API Key 密钥。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/MiniMax-%E5%AE%98%E6%96%B9.png)

### 1.2 方式二：私有化部署

参考 [https://github.com/MiniMax-AI/MiniMax-01](https://github.com/MiniMax-AI/MiniMax-01) 进行部署

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型，并选择前面配置的 MiniMax API 密钥。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| MiniMax-M3 | 512000 |
| MiniMax-M2.7 | 196608 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 MiniMaxChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.minimax` 配置项，替换成你的！

```
yudao:
  ai:
    minimax: # MiniMax
      enable: true
      api-key: ${MINIMAX_API_KEY}
      model: MiniMax-M3
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，MiniMaxChatModelTests 里有对应的测试用例，可以参考。
