## 1. 申请密钥

由于 Google Gemini 是非开源的模型，所以无法私有化部署，需要去官网申请 API Key，然后通过 Spring AI 提供的客户端接入。

不过，目前市面上有很多 Gemini 的中转 API 服务，通过购买这些服务，也能实现接入。

疑问：什么是“中转 API 服务”？

简单来说，就是有人通过一定的渠道，获取了大量的 Gemini、MidJourney 等 API 账号，然后部署一个 API 池子（服务）。

中转人卖给你一个 API KEY 令牌，你就可以把 AI 请求发送到他的池子：池子采取一定的算法选取一个 API 账号帮你把请求发送到大模型后端，然后再把大模型返回的结果转发给你。

下面，我们来看看这两种方式怎么申请？

### 1.1 方式一：官方 API 申请

① 在 [Google AI Studio](https://aistudio.google.com/app/apikey) 上，点击「创建 API 密钥」，创建一个 API Key 密钥。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为项目默认使用 Google Gemini 官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/Gemini-%E5%AE%98%E6%96%B9.png)

友情提示：官方的 API 禁止国内直接访问，需要有 VPN 代理~

### 1.2 方式二：中转 API 申请

提供中转 API 服务的有很多，也可以 Google 直接搜索“gemini API 中转”，例如说：

- [TeamoRouter](https://teamorouter.com/?i=24111b709f) 【最佳推荐，官方 10% 左右的价格，Codex/Claude Code 也可以用】
- [毫秒 API](https://api.holdai.top/register?aff=EcRu)
- [AIHubMix](https://aihubmix.com?aff=E13A)

---

购买完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。需要填写“密钥” + “自定义 API URL”（因为让 Spring AI 使用该地址）。

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 GoogleGenAiChatModel 等对象，需要把 `application.yaml` 配置文件里的 `spring.ai.google.genai` 配置项，替换成你的！

```
spring:
  ai:
    google:
      genai: # 谷歌 Gemini
        api-key: ${GEMINI_API_KEY}
        chat:
          model: gemini-3.5-flash
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，GeminiChatModelTests 里有对应的测试用例，可以参考。

## 666. Gemma 如何接入？

Gemma 是 Gemini 的[开源版本](https://github.com/google-deepmind/gemma)，可以进行私有化部署。

整个的接入，类似 [《【模型接入】LLAMA》](https://doc.iocoder.cn/ai/llama)。下面，我简单写下，有疑问可以星球提问哈！主要是，貌似也没听说哪个团队或者朋友在使用~

① 访问 [Ollama 官网](https://ollama.ai/download)，下载对应系统 Ollama 客户端，然后安装。

② 安装完成后，在命令中执行 `ollama run gemma4` 命令，一键部署 `gemma4` 模型。

③ 之后，需要使用 Spring AI 的 [spring-ai-ollama](https://github.com/spring-projects/spring-ai/tree/main/models/spring-ai-ollama) 进行接入。

不知道它怎么使用的话，可以看看 [《Spring AI : Java Integration with Large Language Models Simplified》](https://medium.com/@freeyecheng/spring-ai-java-integration-with-large-language-models-simplified-04873df6a538) 博客。
