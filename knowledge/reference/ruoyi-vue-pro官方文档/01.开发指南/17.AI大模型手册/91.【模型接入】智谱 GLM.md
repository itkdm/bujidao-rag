| 功能 | 模型 | Spring AI 客户端 |

| AI 绘画 | CogView | 暂未接入 |

## 1. 申请密钥

智谱 AI 有开源模型，可以私有化部署。

不过它最新、最强的模型通常没有开源，所以只能通过官方的 API 服务接入。

### 1.1 申请智谱 AI 密钥

① 在 [智谱 AI 开放平台](https://www.bigmodel.cn/invite?icode=ANYhs5i3q9fak%2Be3nUWbhGczbXFgPRGIalpycrEwJ28%3D) 上，注册一个账号。目前，默认注册就送 2500w tokens，还是蛮爽的。

② 在 [API keys](https://open.bigmodel.cn/usercenter/apikeys) 菜单，复制系统默认 API key 即可。

---

申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

![官方的密钥配置](https://doc.iocoder.cn/img/AI%E6%89%8B%E5%86%8C/%E6%A8%A1%E5%9E%8B%E6%8E%A5%E5%85%A5/%E6%99%BA%E8%B0%B1-%E5%AE%98%E6%96%B9.png)

## 2. 模型配置

友情提示：

### 2.1 AI 对话

使用 [《AI 对话》](https://doc.iocoder.cn/ai/chat/) 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型，并选择前面配置的智谱 API 密钥。

不同模型的 `max_tokens`（回复数 Token 数）上限不同，可以参考下表填写：

| 模型标识 | max_tokens 最大输出 Tokens |
| --- | --- |
| glm-5.2 | 131072 |
| glm-5.1 | 131072 |
| glm-5 | 131072 |
| glm-5-turbo | 131072 |

## 3. 如何使用？

① 如果你的项目里需要直接通过 `@Resource` 注入 ZhiPuChatModel 等对象，需要把 `application.yaml` 配置文件里的 `yudao.ai.zhipu` 配置项，替换成你的！

```
yudao:
  ai:
    zhipu: # 智谱 AI（GLM）
      enable: true
      api-key: ${ZHIPU_API_KEY}
      model: glm-5.2
```

② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 `#getChatModel(...)` 方法，获取对应的模型对象。

---

① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

另外，ZhiPuAiChatModelTests 里有对应的测试用例，可以参考。
