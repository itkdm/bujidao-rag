## 1. 演示地址

HRM（Human Resource Management，人力资源管理系统）用于维护企业从招聘、入职到考勤、社保、薪资、绩效的完整人事链路，以员工主档为中心，串联组织、招聘、考勤、社保、薪资、绩效六大业务域。

### 1.1 HRM 管理后台

- 演示地址：[http://dashboard-vue3.yudao.iocoder.cn/](http://dashboard-vue3.yudao.iocoder.cn/)
- 菜单："HRM 人力资源"下的「HR 工作台」「组织管理」「招聘管理」「员工管理」「考勤管理」「社保管理」「薪资管理」「绩效管理」
- 仓库：[https://github.com/yudaocode/yudao-ui-admin-vue3](https://github.com/yudaocode/yudao-ui-admin-vue3) 的 `hrm` 目录，基于 Vue3 + Element Plus 实现

![管理后台](https://doc.iocoder.cn/img/HRM%E4%BA%BA%E5%8A%9B%E8%B5%84%E6%BA%90/%E7%BB%84%E7%BB%87/HR%E5%B7%A5%E4%BD%9C%E5%8F%B0.png)

### 1.2 HRM 员工端

员工端不是另一套账号、前端或数据库，而是同一个管理后台下的「HRM 员工端」菜单。员工档案的 `user_id` 绑定后台账号后，该账号即可查看本人的档案、考勤、社保、工资条和绩效任务。

- 菜单："HRM 人力资源"下的「HRM 员工端」
- 仓库：[https://github.com/yudaocode/yudao-ui-admin-vue3](https://github.com/yudaocode/yudao-ui-admin-vue3) 的 `hrm/portal` 目录

Portal 接口通过当前登录账号反查员工主档，只返回本人数据；未绑定员工档案时，页面展示开通引导。

![员工端](https://doc.iocoder.cn/img/HRM%E4%BA%BA%E5%8A%9B%E8%B5%84%E6%BA%90/%E7%BB%84%E7%BB%87/%E4%B8%AA%E4%BA%BA%E5%B7%A5%E4%BD%9C%E5%8F%B0.png)

支持 Spring Boot 单体、Spring Cloud 微服务架构

- 微服务仓库： [https://github.com/YunaiV/yudao-cloud](https://github.com/YunaiV/yudao-cloud) 的 `yudao-module-hrm` 服务

## 4. 功能描述

主要分为 6 个业务域：组织与员工、招聘管理、考勤管理、社保管理、薪资管理、绩效管理，另外提供一套面向员工的自助端。

业务以员工主档为中心：候选人办理入职后生成员工，员工再进入考勤、社保、薪资和绩效流程；员工端复用同一份员工档案，只开放本人数据和本人可办理的操作。

![HRM 功能列表](https://doc.iocoder.cn/img/common/hrm-feature.png)

## 5. 表结构

HRM 共 **50** 张表，表名统一以 `hrm_` 为前缀。部门复用 `system_dept`、后台账号复用 `system_users`，它们不计入这 50 张表。表之间采用逻辑关联，不声明物理外键，并统一包含审计、逻辑删除和多租户字段。

![HRM 全表关系](https://doc.iocoder.cn/img/HRM%E4%BA%BA%E5%8A%9B%E8%B5%84%E6%BA%90/%E6%A6%82%E8%A7%88/%E6%A8%A1%E5%9D%97%E5%85%B3%E7%B3%BB.svg)

| 模块 | 子前缀 | 表数量 | 核心职责 |
| --- | --- | --- | --- |
| 共享配置 | hrm_config | 1 | 员工字段设置、招聘淘汰原因等业务配置 |
| 员工管理 | hrm_employee* | 12 | 员工主档、经历、合同、异动、离职、附件和备忘 |
| 招聘管理 | hrm_recruit_* | 5 | 职位、职位类型、候选人、面试和招聘渠道 |
| 考勤管理 | hrm_attendance_* | 4 | 考勤组、节假日、打卡和请假 |
| 社保管理 | hrm_insurance_* | 5 | 方案、方案项目、员工资料、月度主表和员工明细 |
| 薪资管理 | hrm_salary_* | 13 | 计薪配置、薪资组、工资项、定调薪、月工资和工资条 |
| 绩效管理 | hrm_performance_* | 10 | 模板、计划、考核实例、阶段、维度、指标、评分和申诉 |

### 5.1 组织管理

HR、团队和个人工作台提供统计、日历与个人备忘，其中只有个人备忘落到 `hrm_employee_personal_note` 表；组织架构直接复用 System 部门，不新建 HRM 表。

- [《【组织】工作台、组织架构》](https://doc.iocoder.cn/hrm/organization/)

### 5.2 员工管理

员工主档是 HRM 的核心，覆盖档案建立、资料维护、入职、转正、异动、离职及再次入职，并按教育、工作、合同、附件等维度扩展子档案。员工字段设置与招聘淘汰原因共用 `hrm_config` 配置表。

- [《【员工】员工管理》](https://doc.iocoder.cn/hrm/employee/)

### 5.3 招聘管理

围绕「**招聘职位 → 候选人 → 面试 → Offer → 转员工**」形成招聘闭环，并通过招聘渠道与淘汰原因统一基础配置。

- [《【招聘】招聘管理》](https://doc.iocoder.cn/hrm/recruit/)

### 5.4 考勤管理

考勤组定义班次、地点、WiFi、特殊日期和扣款规则；打卡记录形成日、月统计，请假由员工端发起并复用 BPM 审批。日月统计为**实时计算**，不落归档快照。

- [《【考勤】考勤管理》](https://doc.iocoder.cn/hrm/attendance/)

### 5.5 社保管理

采用「**当前配置 + 月度快照**」设计：参保方案定义企业与个人缴费项目，员工参保档案提供核算基础，月度社保表按月归档并保留历史。

- [《【社保】社保管理》](https://doc.iocoder.cn/hrm/insurance/)

### 5.6 薪资管理

按「**计薪设置 → 薪资档案 → 月度工资 → 工资条**」四段组织：计薪周期、计税规则、薪资组和工资项组成基础配置；员工定调薪后进入月度工资核算，核算结果通过工资条发放给员工。

- [《【薪资】计薪设置、薪资档案》](https://doc.iocoder.cn/hrm/salary/config/)
- [《【薪资】月度工资、工资条》](https://doc.iocoder.cn/hrm/salary/payroll/)

### 5.7 绩效管理

指标模板和结果模板用于配置绩效计划；计划启动后，参评员工依次完成制定指标、确认目标、评分、结果审核、结果确认和申诉，最终沉淀为绩效档案。

- [《【绩效】绩效模板、绩效计划》](https://doc.iocoder.cn/hrm/performance/template-plan/)
- [《【绩效】绩效考核、绩效档案》](https://doc.iocoder.cn/hrm/performance/assessment/)

### 5.8 员工自助

员工端提供个人工作台、本人档案、考勤与请假、社保、工资条、绩效任务和绩效档案。

管理端负责规则配置与全员管理，员工端负责查看本人数据和完成本人流程节点，因此不单独成篇，各业务手册的「员工端」小节即对应功能。
