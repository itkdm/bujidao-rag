# candidate/main/

## 目录定位

本目录存放拟晋升到 `knowledge/main/` 的候选知识。内容必须具有跨应用、跨系统或全局约束的潜在价值，但当前证据或确认条件尚未闭环。

## 应包含的内容

- 可能成为全局规则、通用术语、跨应用流程或共享技术约束的候选结论。
- 影响多个应用、无法合理归入单一 appCode 的待验证知识。

## 不应包含的内容

- 单一应用范围内的候选：进入 `candidate/applications/<appCode>/`。
- 目标范围本身无法判断的内容：必要时进入 `candidate/unclassified/`。
- 已确认的全局知识：进入正式 `main/`。

## 维护规则

- 保留未来 `main/` 内的相对路径；只有出现真实候选时才建立 `rules/`、`tech/` 或其他目标分类。
- 候选必须证明其可能具有跨应用价值，不能仅因暂时不知道放哪里就进入本目录。
- 每个新建子目录必须具有 README 与 INDEX；确认后按镜像路径迁入正式 `main/`。
